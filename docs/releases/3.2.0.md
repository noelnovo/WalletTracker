## WalletTracker 3.2.0-alpha

- New Debts tab: track money people owe you, group by person with outstanding
  totals, mark debts paid (or back to unpaid) with clear card states.
- People are stored as records; the debt editor suggests saved names so new
  debts can be assigned to the same person.
- Server-provided configuration: the app reads supported currencies from
  `/api/v2/properties` instead of hardcoding them; defaults apply offline.
- JaCoCo code coverage reporting for unit tests.
- Versioning: version name carries the `-alpha` suffix while this line is in
  development; production tags remain strict `vX.Y.Z`.

### Compatibility and updates

For security, old v1 biometric password decryption is retired. V1 users sign in
once by password and may then use current v2 fingerprint login. Stored wallet
records and explicit legacy financial-data migration remain intact; never clear
application data to upgrade. Current v2 biometric unlock is unchanged.

Retains API v2, the production package and signing certificate, and the 3.1.x
record formats. Debts and people sync through the existing record store; the
backend (2.2.0) accepts the new record kinds. No database migration is
required on the device. Install as an update; never uninstall or clear wallet
data. Production publication follows the protected MAIN-tag workflow and the
existing required production approval.
