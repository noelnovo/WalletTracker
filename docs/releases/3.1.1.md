## WalletTracker 3.1.1

- Automatically show the system fingerprint prompt when reopening a remembered
  account. Cancellation does not loop; manual retry and password fallback remain
  available. Backgrounding cancels pending authentication safely.
- Replace prominent fuchsia cards and gradients with neutral light surfaces and
  black/charcoal dark surfaces. Keep fuchsia for accents, selected navigation,
  focus, and primary actions.
- Keep the bottom navigation alive during tab switches and sync-status updates.
  Cache tab pages, load/decrypt wallet records off the UI thread, and preserve
  scroll position across tab switches and activity recreation.
- Organize automation into CI/build/release/shared scripts, separate automation
  tests and non-secret configuration, and move retained documentation into
  `docs/`. Update the README and remove obsolete v1 screenshots/documentation.

### Compatibility and updates

This patch retains API v2, the existing production package and signing
certificate, and the 3.1.0 bill format. It introduces no database migration or
backend deployment requirement. Install as an update; never uninstall or clear
wallet data. Production publication follows the protected MAIN-tag workflow and
the existing required production approval.
